## 📌 Project Overview

The Customer Intelligence System is an end-to-end Machine Learning solution designed to transform raw socio-economic data into actionable insights through customer segmentation and predictive analytics.

This project combines unsupervised learning, supervised learning, and ensemble techniques to identify meaningful groups, predict segment membership, and support data-driven decision making.

## 🎯 Objectives

- Discover hidden patterns in customer data.
- Segment customers into meaningful groups.
- Build predictive models for segment classification.
- Compare ensemble learning algorithms.
- Generate actionable business intelligence.

## 🧠 Machine Learning Techniques

### Clustering
- K-Means Clustering
- DBSCAN Clustering
- Elbow Method
- Silhouette Score Evaluation

### Classification
- Random Forest Classifier
- XGBoost Classifier

### Data Processing
- StandardScaler
- PCA Dimensionality Reduction
- Feature Importance Analysis
